# Vault

Это декларация того, что нужно пользователю: фичи, элементы системы, связи, критерии.
**Пишет только пользователь** (или ИИ по его словам, с подтверждением). Loop-агент читает,
но не пишет.

## Формат

- Одна сущность — один файл.
- Связи — `[[имя-заметки]]`, как в Obsidian, но Obsidian не обязателен.
- Шапка:

```markdown
---
id: имя
статус: черновик | принято
---
```

- Разделы: «Что это», «Связи», «Критерии приёмки», «Открытые вопросы».
- Критерий приёмки — проверяемый сценарий, не «удобно» и не «красиво».

## Разделы

- `features/` — что пользователь должен уметь.
- `system/` — из каких частей состоит система и где границы.
